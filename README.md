# RAG Agents for Research Papers

Developed a RAG (Retrieval-Augmented Generation) agent for answering questions about my research papers.

## Overview

This repository implements a RAG agent that combines the power of large language models (LLMs) with tailored information retrieval to answer questions relating to your research papers. The agent provides accurate and context-aware responses by retrieving relevant information from your documents, and generating answers using advanced machine learning models.

## Features

- **Contextual Q&A:** Ask questions about your research papers and get detailed, context-aware answers.
- **Retrieval-Augmented Generation:** Combines retrieval of relevant information with capabilities of generative models.
- **Jupyter Notebooks:** Easy-to-understand and interactive code walkthroughs.
- **Extensible & Customizable:** Add or swap papers, tune retrieval systems, and experiment with model parameters.

## Language Composition

- Jupyter Notebook: 83.7%
- Python: 16.3%

## Getting Started

### Prerequisites

- Python 3.7 or later
- Jupyter Notebook
- `pip` for installing dependencies

### Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/shreyasb032/rag-agents-for-research-papers.git
    cd rag-agents-for-research-papers
    ```

2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

3. (Optional) Install Jupyter Notebook if you don’t have it:
    ```bash
    pip install notebook
    ```

### Usage

1. Start Jupyter Notebook:
    ```bash
    jupyter notebook
    ```

2. Open the provided notebook(s) and follow instructions inside to load your research papers and interact with the RAG agent.

## Repository Structure

- `notebooks/` — Jupyter Notebooks demonstrating RAG agent workflows.
- `src/` — Core Python scripts and modules.
- `requirements.txt` — Python dependencies needed for this project.
